# XM

Verified on: 2026-10-06

XM is a broker. No retail XM REST API was verified. Accounts connect with the MT4 or MT5 login, investor password, and server from the Members Area. TradeFix does not ask for the XM website password.

Server presets are not shipped. Type the server name. Custom values are allowed.

Transport is the MT bridge. See mt5.md.
